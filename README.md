# FSM-Based Traffic Light Controller

## Project Overview
This project implements a Finite State Machine (FSM)-based traffic light controller using Verilog HDL. The design models traffic light transitions between different states and is verified through simulation.

## Objectives
- Design a traffic light controller using FSM concepts.
- Implement the digital logic using Verilog HDL.
- Verify the design using a Verilog testbench.
- Observe signal transitions using waveform simulation.
- Explore RTL synthesis using Yosys.

## Tools and Technologies
- **Verilog HDL** — RTL design
- **Icarus Verilog** — Simulation
- **GTKWave** — Waveform visualization
- **Yosys** — RTL synthesis

## Project Files
| File | Description |
|---|---|
| `traffic_light.v` | Verilog RTL design of the traffic light controller |
| `traffic_light_tb.v` | Testbench used to simulate and verify the design |
| `traffic_light.vcd` | Waveform data generated during simulation |

## Design and Verification Flow
1. Write the traffic light controller in Verilog.
2. Create a testbench to apply inputs and observe outputs.
3. Run the simulation using Icarus Verilog.
4. Inspect signal transitions in GTKWave.
5. Perform RTL synthesis and examine the synthesis results.

## Learning Outcomes
- Understanding FSM-based digital design.
- Writing and verifying RTL using Verilog HDL.
- Simulating digital circuits and analyzing waveforms.
- Gaining practical exposure to RTL synthesis.
